# Análise Imobiliária Algarve

Projeto de Ciência dos Dados focado na análise e modelação preditiva do mercado imobiliário no Algarve.

## Tecnologias utilizadas

- Python
- Pandas
- Scikit-Learn
- Streamlit
- Google Colab

## Objetivos

- Analisar a evolução do preço por m² no Algarve
- Integrar variáveis económicas e turísticas
- Aplicar modelos preditivos
- Disponibilizar uma aplicação web interativa
